## اجرای ۱ — ۱۴۰۵/۰۷/۰۹ تا ۰۷/۱۰ (۲۰۲۶-۱۰-۰۱/۰۲) — بنیان‌گذاری

### Skill Version
**v0.1.0**. مخزن در ابتدا فقط یک README خالی داشت؛ هیچ Skill یا گزارش قبلی وجود نداشت.

### Research Performed
- **منابع اولیه (راستی‌آزمایی‌شده)**: web.dev (Core Web Vitals، TTFB، LCP، CLS)، W3C (موارد جدید WCAG 2.2)، OWASP (فهرست Top 10:2025 و سه Cheat Sheet: ذخیرهٔ رمز، SSRF، هدرها)، Google Search Central (ساختار URL، sitemap، robots.txt، hreflang)، مشخصات رسمی Agent Skills و مستندات Claude Code.
- **آزمایش‌های تکرارپذیر**: رفتار `Intl` برای تقویم و ارقام فارسی، قالب‌بندی ریال، نبود ساعت تابستانی ایران از ۱۴۰۲ (آخرین دورهٔ آن تابستان ۱۴۰۱ بود)، تطابق سال‌های کبیسهٔ ICU با قاعدهٔ ۳۳ ساله (۱۳۸۰–۱۴۵۰)، قاعدهٔ جمع و `ListFormat` فارسی، ناکافی‌بودن NFKC برای ی/ک/ارقام، و رفتار bidi در Chromium.
- **منابع ثانویه (با برچسب ASSUMPTION/FACT-S)**: قانون تجارت الکترونیکی (ماده ۳۷: حق انصراف ۷ روز کاری)، اینماد، جریان پرداخت زرین‌پال (مستندات هنگام خواندن ۵۰۳ داد)، خاموشی اینترنت خرداد ۱۴۰۴ (ویکی‌پدیا با ارجاع به NetBlocks/Cloudflare)، گزارش خاموشی دی ۱۴۰۴ (فقط یک منبع ثانویه؛ **تأییدنشده**)، حذف چهار صفر از ریال (مصوبهٔ مجلس و تأیید شورای نگهبان؛ نام واحد جدید و زمان‌بندی در منابع متناقض است).
- منابع کم‌اعتبار (وبلاگ‌ها) عمداً نادیده گرفته شدند.

### Audit Findings
چون Skill وجود نداشت، «ممیزی» روی خروجی‌های همین اجرا انجام شد و این ضعف‌ها پیدا شد:
1. دو ردیف از جدول خطرات bidi که از حافظه نوشته بودم در بازتولید **رد شد** (نقطه‌گذاری پس از عبارت انگلیسی، پرانتز).
2. جدول مسیریابی باعث می‌شد Agent کل Evidence Register (۱۷KB) را بخواند.
3. چارچوب «بسازیم یا آماده استفاده کنیم؟» (D-BUILD) اصلاً وجود نداشت.
4. D-HOST گزینه می‌داد ولی قاعدهٔ تصمیم نداشت.
5. فرایند ۱۱ سند پیش‌فرض داشت (برای سایت ۵ صفحه‌ای زیاد است).
6. امنیت در حد «تست کن» مانده بود و ابزار اجرایی نداشت.
7. وزن ۵٪ برای RTL در انتخاب UI kit اجازه می‌داد کیت ضعیف برنده شود.
8. شکاف محتوایی: راهنمای اختصاصی هر نوع سایت نبود.
9. باگ‌های خود ابزارها (Linter: ستون تاریخ اشتباه؛ Page Audit: پیام `dir="null"`، خطای کاذب چک‌باکس بومی؛ تست اول کبیسه با خطای یک‌واحدی؛ نرمال‌سازی موبایل با `+98 0912…`).

### Changes
ایجاد کامل Skill: `SKILL.md` (مسیریاب + ۱۲ قانون عملیاتی)، ۲۱ مرجع، ۴ قالب (شامل `starter-lite`)، ۶ اسکریپت (+ تست «حقایق پلتفرم») با ۴۱ تست (ابزارهای فارسی، RTL، کنتراست، Page Audit مرورگری، ترتیب bidi، Smoke امنیتی)، Evidence Register با ۳۴ ادعای برچسب‌دار، ۶۳ Edge Case، ۲۸ Anti-pattern، ۴۲ Failure Mode، گیت‌های G0–G6، و سامانهٔ `meta/` (رویه، Linter، سؤال‌های باز، Red Team، اعتبارسنجی).

### Validation
چهار سناریوی فرضی پیمایش شد: فروشگاه عسل (Standard)، دفتر حقوقی/شرکتی (Lite)، SaaS صورتحساب (Heavy)، رزرو نوبت کلینیک (Standard). نتیجه: Skill پس از ۴ اصلاح (راهنمای نوع سایت، D-BUILD، قاعدهٔ D-HOST، مجموعهٔ Lite) تصمیم‌های قطعی می‌دهد؛ برای SaaS عمق دامنه M1 است. اجرای واقعی: `starter-lite` با Page Audit (۳۲۰/۳۶۰/۷۶۸px، بلاک‌شدن میزبان‌های خارجی) بدون خطا. ۴۱ تست پاس، Linter صفر خطا.
